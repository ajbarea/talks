Federated learning has a reproducibility tax.
Different data splits. Different aggregation hyperparameters. Different attack implementations. Same paper, different numbers, every re-run.
InteFL flattens it.

A full-stack platform for running, attacking, and defending distributed ML simulations.

One JSON config:
→ partitioned datasets
→ N federated clients
→ aggregated metrics, plots, and attack snapshots. React dashboard or CLI.
→ 9 strategies (FedAvg, Krum, Multi-Krum, Bulyan, RFA, Trimmed Mean, PID, Trust, ArKrum)
→ 11 attack types (label flipping, backdoors, model poisoning, Byzantine perturbation...)
→ 20+ datasets (FEMNIST, FLAIR, CIFAR-100, MedMNIST, HF text)

Flower + Ray · PyTorch + PEFT · FastAPI + Celery + Redis · React + Vite

Tried to reproduce an FL paper recently? What tripped you up first: data splits, hyperparameters, or the attack implementation itself?
