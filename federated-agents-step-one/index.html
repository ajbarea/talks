    1 · The bigger problem

    Coding agents need a company's house style, which sits in private review history

    • Federated learning: train at home, average only what is shared

    4 · The method

    A confirmatory study fixes its hypotheses before the data; mine compare adapters

    Own-half adaptertrained on the half this test code comes from
    H1: own beats sibling
    Sibling-half adaptertrained on the organization's other half
    H2: sibling beats foreign
    Foreign adaptertrained on as much C++ from another organization

    Each adapter trains on examples; all three score the same held-out test code.

    "The researcher has a fixed hypothesis… the objective of the study is to find out whether the hypothesis is supported by the facts/data."

    H1: on held-out code from one half, the adapter trained on that half beats the one trained on the other half.

    H2: that other half's adapter beats a foreign one, tested on Qt's C++ with Chromium as foreign.

    • Confirmatory: fixed hypotheses, data can only support or refute
    • H1: own half beats sibling half
    • H2: sibling beats foreign, Qt against Chromium
    4 · The method

    The pass rule is fixed: every test's confidence interval must sit entirely above zero

    0 δ, smallest effect
    supported
    bounded
    inconclusive

    The score: how much probability an adapter gives the developer's real fix, per token.

    δ = : each token about % more likely, set as one more exact fix per hundred comments.

    H1 passes only if all tests pass: organizations, two scores, each averaged over at least runs.

    Intervals are illustrative; δ is the study's own value, in nats per token, the log-probability scale of the score. A confidence interval is the range the data leave plausible.

    Why are there no results yet?

    A Stage 1 report is the plan, so it must carry no results. Results come in Stage 2, after the sealed test months are fetched.

    The field's reason: in psychology, one study found 96% positive results in standard papers and 44% in Registered Reports, on the first hypothesis of each paper.

    Scheel, Schijen, Lakens (2021), An Excess of Positive Results, doi:10.1177/25152459211007467. The authors note this does not prove Registered Reports reduce bias.

    Why code review data?

    House style is what reviewers enforce and rarely write down, and a review pairs a comment with the code that answered it. That pairing is the training example.

    The revision that followed the comment is a label a person produced, and the data is public for these hosts, so what leaks can be checked against known origins.

    Back to the questions

    How does this relate to InteFL?

    Sphragis has no federated learning in it. It is centralized measurement, in its own repository: one adapter per project half, and no aggregation.

    InteFL is the lab's federated framework. Its aggregation and attack work becomes relevant at step two, once there is an adapter to federate.

    Which FL stack step two runs on is decided when it starts.

    Back to the questions

    What is a LoRA adapter?

    A small add-on, trained beside a frozen base model, in low-rank adaptation. The study trains one per project half at rank on .

    It is the unit a federated step would average: small, trainable at each company, and the only thing that could travel.
