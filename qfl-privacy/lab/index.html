The data stays home; the gradient travels

In federated learning, clients such as phones or hospitals train one shared model without pooling their data. Each round, a client trains the current model on its own data and sends back only an update, here a gradient. The server averages the updates into the next model.

The gradient is a list of numbers, one per trainable angle, so it feels private. But a curious server knows the circuit. It can guess an input, compute that guess's gradient, and adjust the guess until the two gradients match. If they match, the guess is usually the input. That is a gradient-matching attack.

This lab runs that attack in your browser on a toy: one qubit, one hidden input. It shows the mechanism. The numbers that answer the research question are the paper's, in the last tab.

ToyThe live panels run a one-qubit data re-uploading circuit, simulated in this page, with the paper's outcome rule and thresholds.
