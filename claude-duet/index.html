    What comes back

    Research preview, announced October 21, 2026. Runs on Claude Opus 5.5; you can't pick the model.

    Duet is Anthropic's proactive personal agent, announced October 21st as a research preview. The key idea is that it has its own computer in Anthropic's cloud, with its own browser. So your phone and laptop can be off, and it keeps working. Every few hours it checks the accounts you've connected, and then it comes to you: a short brief each morning, dashboards, forecasts, meetings on your calendar. In Anthropic's words, the Claude app waits for you to open a chat; Duet comes to you. So what can it touch? Sources: Anthropic's announcement and product page; help center.

    Duet works through your accounts, using the same marketplace of over six thousand connectors and plugins as the rest of Claude. Much it does on its own: checking accounts, building dashboards, writing forecasts. But before it sends a message, makes a payment, signs a document or deletes anything, it shows you exactly what it's about to do and waits for your yes. Some things it won't do even then, like trading stocks. It's a waitlist preview for Pro, Max and Ultra plans in the US, and its work counts against your plan's usage.     Claude Code is the opposite design. It runs in your repository and your terminal. It reads your code, edits files, and runs the same commands you would.     4 · A short demo

    A six-line hook stops pip, and Claude switches to uv by itself

    › Add the requests package. Use pip install requests.

    ● Bash pip install requests

    ✕ Blocked: this lab uses uv. Run: uv add <package>

    The hook blocked pip and asked for uv. I'll follow that.

    ● Bash uv add requests

    ✓ pyproject.toml now lists "requests>=2.34.2"

    A real headless run (claude -p, Claude Haiku 5.5, permission prompts off), October 31, 2026, trimmed. Exit code 2 blocks the command and hands Claude the message.

    Here's a hook. Say your lab has settled on uv instead of pip, so packages land in the project file and everyone gets the same versions. Writing that in a README is a suggestion. A hook is a rule. This one reads the command Claude is about to run, and if it's a pip install, it blocks it and says why. I asked Claude to pip install requests. It tried, the hook refused, and Claude read the message, ran uv add instead, and the package landed in the project file. I never stepped in, and this run had permission prompts switched off, so the hook held on its own. Live, on Opus, it stops at the block; I tell it to follow the hook, and it runs uv add. Here's how you could try it. Sources: Claude Code hooks guide and reference; the run's transcript, October 31.

    So how would you start? Monday morning, install it with one command. Open your repository, run claude, and type slash init: it reads your code and writes a starting file with your build commands and conventions. Add one rule you care about as a hook. Then give it one small, checkable task, like a failing test. Three cautions. It needs a paid plan or an API account; Anthropic also has a discounted Team plan for scientists that a PI can apply for. It makes confident mistakes, so read every change before you commit. And what it reads is sent to Anthropic, so keep private data out and check your training setting. I'm happy to sit with anyone for half an hour to set it up. Sources: Claude Code overview, memory and data-usage docs; Claude pricing; Team plan for scientists.
