# Google Vids: reference for a browser agent

Researched 2026-10-31. Google help pages carry no date unless noted. "Doc" means a Google page states it. "Inferred" means nobody has checked it in the UI. Repo paths are relative to `videos/`.

## 1. What a project is

- A Vids file lives in Drive with MIME type `application/vnd.google-apps.vid` ([Drive MIME types](https://developers.google.com/workspace/drive/api/guides/mime-types)).
- A video is a run of **scenes**. Each scene holds text, images and video, and has transitions between scenes. Timing sits on **object tracks** in a timeline ([Get started](https://support.google.com/docs/answer/15082958?hl=en)).
- New start-menu options: Create AI videos, Edit videos, AI avatar, Convert Slides, Record, Upload, Templates, Blank Vid ([Get started](https://support.google.com/docs/answer/15082958?hl=en)).
- Sizes: Widescreen 16:9, Vertical 9:16, Square 1:1 ([Change video size](https://support.google.com/docs/answer/16545758?hl=en); vertical and square launched [Oct 2025](https://workspaceupdates.googleblog.com/2025/10/vertical-square-videos-google-vids.html)).

| Limit | Value | Source |
|---|---|---|
| Video length | 30 min | [Get started](https://support.google.com/docs/answer/15082958?hl=en) |
| Imported clip | 95 min or 4 GB; trim to 30 min before other edits | [Limits](https://support.google.com/docs/answer/16286470?hl=en) |
| Objects per video | 50 video + 50 audio (music, SFX, voiceover count) | [Limits](https://support.google.com/docs/answer/16286470?hl=en) |
| Version history | No number given; at the cap, make a copy | [Limits](https://support.google.com/docs/answer/16286470?hl=en) |
| Collaborators at once | 100 | [Best practices](https://support.google.com/a/users/answer/15599399?hl=en) |
| Editing on mobile | Not available | [Best practices](https://support.google.com/a/users/answer/15599399?hl=en) |

**Export.** MP4 or GIF download, MP4 to Drive, or straight to YouTube as Private ([Get started](https://support.google.com/docs/answer/15082958?hl=en); [YouTube export, 2026-04-02](https://workspaceupdates.googleblog.com/2026/04/export-google-vids-directly-to-youtube.html)). Google lists 1080p ([Best practices](https://support.google.com/a/users/answer/15599399?hl=en), an older page that still says 16:9 only). A real 16:9 export measured h264 1920x1080 at 30 fps, AAC 44.1 kHz stereo, an English `mov_text` caption track, moov at the end (`05-haunted-terminal/TOOLING-NOTES.md:8`). The 9:16 export resolution is unconfirmed.

**Captions.** View > Closed captions > Autogenerated (English speech). Styled captions come from the sidebar's Captions. Edit under Tools > Closed captions ([Captions](https://support.google.com/docs/answer/14953386?hl=en); styling added [2026-09-30](https://workspaceupdates.googleblog.com/2026/09/customize-style-of-your-captions-in-Google-Vids.html)).

**Sharing** works as in Docs: Viewer, Commenter, Editor ([Get started](https://support.google.com/docs/answer/15082958?hl=en)). **Version history:** the shared Docs Editors article says Last edit / Version history at top right ([Find what's changed](https://support.google.com/docs/answer/190843?hl=en)). Unconfirmed in Vids itself.

**Deletion.** Trash keeps a file 30 days, then deletes it forever. People it was shared with keep access until then, and it still counts against storage ([Drive delete](https://support.google.com/drive/answer/2375102?hl=en)).

## 2. AI features

| Feature | Facts | Source |
|---|---|---|
| Help me create (draft from prompt) | Blank Vid, then File > Storyboard. Type `@` to attach a Doc, Slides or PDF. Outputs outline, scenes, media, script, voiceover. Works only on a **new, unedited, unnamed** file | [Plan with AI](https://support.google.com/docs/answer/15067819?hl=en) |
| Docs, PDF or Word to video | Summary video with script and narration. Plans include Google AI Plus, Pro, Ultra. Menu path unconfirmed | [2026-09-02 post](https://workspaceupdates.googleblog.com/2026/09/turn-google-docs-pdfs-and-word-files-into-video-summaries-in-Google-Vids.html) |
| Slides to video | Paste slides into the timeline: each slide becomes a scene and its speaker notes become the script. Themes, animations and videos do not carry over | [Best practices](https://support.google.com/a/users/answer/15599399?hl=en) |
| AI video clips (Gemini Omni; earlier posts say Veo) | 3 to 10 s per clip, 16:9 or 9:16, 720p or 1080p, 24 fps. Up to 7 reference images plus an avatar. Extend works only on clips from **this session**. Edit changes only the last 10 s of an upload. History clears when the tab closes, so Insert first | [Omni clips](https://support.google.com/docs/answer/16143507?hl=en) |
| Omni 1.1 Flash | Exact duration control, 1080p generation or upscale, better extension | [2026-09-23 post](https://workspaceupdates.googleblog.com/2026/09/gemini-omni-11-flash-now-in-vids-with-improved-extension-quality-1080p-and-duration-control.html) |
| Preset and custom avatars | Up to 60 s per avatar video. Audio tags (type `[`) set pace and emotion. "Avatar outdated" badge after a script edit | [AI avatars](https://support.google.com/docs/answer/16334946?hl=en) |
| AI voiceover | Right rail Voiceover > Current scene or All scenes. Script max 2,500 characters, plain text, 23 languages | [Voiceovers](https://support.google.com/docs/answer/15070345?hl=en) |
| Image generation | Nano Banana Pro, 30 a month on Workspace and AI Pro | [Usage limits](https://knowledge.workspace.google.com/ai/usage-limits-gemini?hl=en) |
| Music | 50 clips of 30 s and 20 full tracks (up to 3 min) a month | [Usage limits](https://knowledge.workspace.google.com/ai/usage-limits-gemini?hl=en) |

Google says generated images and videos "are for use only within Vids" ([Omni clips](https://support.google.com/docs/answer/16143507?hl=en)).

**Personal avatar.** Start menu > Personal avatar. Scan the QR code. On a phone, record your face and voice, with head turns. Then click Next ([Personal avatar](https://support.google.com/docs/answer/16970930?hl=en)). Rules:

- 18 or older, English only, not in the EEA, Switzerland or UK.
- The account owner records it. It may depict only the account holder ([Google blog, 2026-07-16](https://blog.google/products-and-platforms/products/workspace/gemini-omni-personal-avatars/)).
- To use it: AI Video > Create > Avatar.
- Retake or delete it at any time. Manage goes to the Google Account, and deleting it there also removes it from the Gemini app.
- Plans: Google AI Pro and Ultra ([2026-07-16 post](https://workspaceupdates.googleblog.com/2026/07/cast-yourself-in-ai-video-clips-using-your-personal-avatar-with-Gemini-Omni-in-Vids.html)). Avatars as clip ingredients on Pro or Ultra are "USA only" ([Omni clips](https://support.google.com/docs/answer/16143507?hl=en)).

**Watermarks.**

- Every generated clip carries an invisible SynthID ([Google blog, 2026-07-16](https://blog.google/products-and-platforms/products/workspace/gemini-omni-personal-avatars/)).
- Gemini media in Vids carries C2PA Content Credentials. Download or export may break that chain, but SynthID survives most edits ([AI labels](https://support.google.com/docs/answer/17560328?hl=en)).
- The repo saw a visible Gemini sparkle mark bottom-right in every clip (`05-haunted-terminal/delivered.md:10`).

- The account drops to personal-account limits: 50 Gemini uses a month in Vids ([Usage limits](https://knowledge.workspace.google.com/ai/usage-limits-gemini?hl=en)) and "only preset AI avatars" ([Vids AI limits](https://support.google.com/docs/answer/15609411?hl=en)).

## 4. Disclosure

- YouTube requires disclosure of realistic content that "makes a real person appear to say or do something they didn't do". Its no-disclosure list includes "cloning one's own voice to create voice overs or dubs" ([YouTube GenAI disclosure](https://support.google.com/youtube/answer/14328491?hl=en)).
- To disclose: Studio > Attributes > AI use > Yes.
- YouTube may auto-label C2PA content, and the creator cannot remove that label.
- Repo rule, stricter: always tick it and say an AI avatar of AJ narrates (`README.md:16`, `vids-rules.md:48`, `05-haunted-terminal/checklist.md:22`).

## 5. Automation

**No Vids editing API.** No Vids or Apps Script reference exists: `developers.google.com/workspace/vids`, `/vids` and `/apps-script/reference/vids` returned 404 (checked 2026-10-31). Workspace Updates posts name none ([label feed](https://workspaceupdates.googleblog.com/search/label/Google%20Vids)). The Drive API handles the file only:

- List or search by MIME type (doc). Rename, trash and copy through `files.update` and `files.copy` (inferred).
- `files.export` fails with `fileNotExportable`. MP4 comes only from `files.download`, a long-running operation that starts as pending ([Export formats](https://developers.google.com/workspace/drive/api/guides/ref-export-formats); [Long-running ops](https://developers.google.com/workspace/drive/api/guides/long-running-operations)).
- Revisions cannot be downloaded with `alt=media` (same page).

**Browser paths.** Base URL `docs.google.com/videos/create` or `vids.new`.

| Action | Path | Basis |
|---|---|---|
| New blank | vids.new > pick Landscape, Portrait or Square > Blank Vid | Doc ([Get started](https://support.google.com/docs/answer/15082958?hl=en)) |
| Set size | Menu bar Video size, or File > Video size > Widescreen, Vertical or Square > Apply | Doc ([Video size](https://support.google.com/docs/answer/16545758?hl=en)) |
| Add scene | A "+" or new-scene control by the scene strip | **Inferred** |
| Stock media | Sidebar Stock > search > click item | Doc ([Stock media](https://support.google.com/docs/answer/15001094?hl=en)) |
| Upload own media | Start-menu Upload is doc. The in-project upload control is **inferred** | Mixed |
| AI clip | Right rail AI video > Create > orientation, 3 to 10 s > Generate > **Insert** | Doc ([Omni clips](https://support.google.com/docs/answer/16143507?hl=en)) |
| Personal avatar clip | AI Video > Create > Avatar > pick it > prompt > Generate | Doc ([Personal avatar](https://support.google.com/docs/answer/16970930?hl=en)) |
| Voiceover | Right rail Voiceover > scope > script > Insert voiceover | Doc ([Voiceovers](https://support.google.com/docs/answer/15070345?hl=en)) |
| Download MP4 | File > Download as MP4 ([Best practices](https://support.google.com/a/users/answer/15599399?hl=en)). Get started says File > Make a copy > MP4, likely a doc error. Look for "Download" | Doc, conflicting |
| Export to Drive | Quick sharing options (next to Share) > Export to Drive > Open now | Doc ([Get started](https://support.google.com/docs/answer/15082958?hl=en)) |
| Export to YouTube | File > Export to YouTube (uploads as Private) | Doc |
| Copy | File > Make a copy | Doc |
| Rename | Click the title at top left | **Inferred** (Docs editors pattern) |
| Remove | File > Move to trash in the editor (**inferred**). Trash in Drive is doc | Mixed |

## 6. Pitfalls from the repo

- "an Omni clip is 10 seconds at most... Whatever a prompt leaves out, Vids makes up... Anything inside double quotes is spoken aloud." (`vids-rules.md:8`; Google confirms 3 to 10 s)
- Music generates "30 seconds at a time" (`vids-rules.md:35`).
- Check that enough generations are left for every segment plus retakes (`vids-rules.md:47`).
- "One narrator for the whole video." When the avatar quota runs out, record your own voice, which uses no AI quota (`youtube-director/references/production-notes.md:8-9`).
- Vids spoke 146 to 218 wpm, so the lint's 150 wpm is too slow (`05-haunted-terminal/TOOLING-NOTES.md:36`).
- "Vids writes two spaces between words and its own spellings" in captions (`05-haunted-terminal/TOOLING-NOTES.md:32`).
- Each track has one single-entry edit list, which YouTube accepts (`05-haunted-terminal/TOOLING-NOTES.md:9`).
- Vids cuts score 0.13 to 0.44. Detect them at a scene threshold of 0.12, not 0.3 (`05-haunted-terminal/TOOLING-NOTES.md:41`).
- A 9:16 crop cuts off the Gemini mark, so it is redrawn (`05-haunted-terminal/TOOLING-NOTES.md:67`). A baked card fell outside the crop (`05-haunted-terminal/delivered.md:82`).
