Three repos. One plugin. The agents do the rest.
techne is my personal Claude Code skill collection: eight skills, one toml file, audited across all my sister repos in parallel.

The lineup:
→ techne:audit runs make targets in dependency order, reconciles output against archived logs
→ techne:ci-audit combs GitHub Actions runs for warnings, fixes what's fixable in-repo
→ techne:docsync verifies doc claims (CLI commands, paths, signatures) against the actual code
→ techne:deslop removes AI-generated slop; techne:reslop rewrites grounded in implementation
→ techne:sisters runs a cross-repo drift audit across the sister projects listed in ~/.claude/techne.toml
→ techne:auto-commit and techne:docs-site round out the set

Write the workflow once. Specialize at the edges, not the center. Every per-project override stays small enough that you don't dread maintaining it.

Install:
/plugin marketplace add ajbarea/techne
/plugin install techne@techne
